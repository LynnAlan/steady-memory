# 隐私模型

个人生活档案可能包含健康、情绪、人际、位置和照片等高度敏感信息。安全目标不是保证任何计算机绝不泄露，而是降低默认暴露面，并让用户知道数据在哪里、谁能读取、谁能修改。

## 建议部署

- 代码仓库可以公开，真实档案必须放在独立私有目录。
- 原图放在档案的 `media/` 目录并由 `.gitignore` 排除，结构化数据只保存路径和哈希索引。
- 普通 ZIP 备份不含媒体；迁移或完整灾备时使用 `backup --include-media`，并留意备份体积和存放位置。
- 整盘加密、系统账户隔离和可信备份由操作系统层提供。
- 备份至少保留一份离线副本，并定期执行 `verify-backup`。
- 恢复使用 `restore-backup <zip> <新目录>`；工具会校验哈希、拒绝危险路径，并且不会覆盖已有目录。
- 分享日志、截图或问题复现前使用合成数据。

## 威胁边界

本项目能降低误覆盖、重复记录、无鉴权 HTTP 和误提交密钥等风险，但无法防御已完全控制用户系统的恶意软件，也不能替代操作系统权限、磁盘加密和可靠备份。
