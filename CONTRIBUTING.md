# Contributing

Thank you for helping improve Steady Memory.

1. Do not use real personal data in issues, fixtures, screenshots, commits, or pull requests.
2. Add or update tests for behavior changes.
3. Run `python -m unittest -v` and the demo-vault validation before opening a pull request.
4. Keep canonical data human-readable and treat indexes as disposable derived state.
5. Changes to archive formats require a schema-version and migration discussion.

Bug reports should include a minimal synthetic vault. Security and privacy issues should follow `SECURITY.md` instead of a public issue.
